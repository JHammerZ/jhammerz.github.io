# L5 Venue Protocol - Notarize Your Show on Bitcoin

## 1. Setup
pkg install opentimestamps-client qrencode git

## 2. Stamp your venue
echo "VENUE_NAME - CITY - $(date)" > venue.txt
ots stamp venue.txt
qrencode -o proof_qr.png "https://yourdomain.com/verify.html"

## 3. Stamp your setlist
echo "SETLIST - $(date)" > setlist.txt
ots stamp setlist.txt
git add. && git commit -m "L5: Show $(date)" && git push

## 4. Verify anytime
ots verify setlist.txt.ots
