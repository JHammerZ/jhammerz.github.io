# Guitaraoke Protocol v1.0

**Author**: Joshua Hamilton (JHammerZ)  
**Definition**: Live human guitar + AI vocal synthesis for real-time audience karaoke.  
**Latency**: <100ms round-trip per H-FID standard.  
**License**: MIT  

## Core Components
1. **Sovereign Input**: Human plays guitar, intent captured
2. **Lysander Relay**: Translates chord progression to vocal melody  
3. **Janus Output**: AI vocal published to audience feed

See [/proof.html](/proof.html) for latency verification.
